# App Privacy

Vue/Vite static site for App privacy policies.

Add a new app by editing `src/data/apps.ts`.

Routes:

- `/{slug}/zh`
- `/{slug}/en`
- `/{slug}/ja`
- `/{slug}/ko`
- legacy: `/app_privacy/{slug}.html`

Cloudflare Pages:

- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
